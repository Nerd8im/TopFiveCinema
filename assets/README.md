# 📦 Pasta `assets/`

Reservada para mídias do site que não são imagens: vídeos.

## 📁 Subpastas

| Pasta | Uso |
| --- | --- |
| `video/` | 🎥 Vídeos, vídeo de fundo nas páginas individuais dos filmes. |

## 📌 Observações

- ▶️ Os **trailers** dos filmes não ficam aqui. Eles são incorporados nas páginas por `iframe` do YouTube.
