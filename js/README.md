# ⚙️ Pasta `js/`

Contém os scripts JavaScript do site.

## 📁 Conteúdo

| Arquivo | Função |
| --- | --- |
| `flimes.js` | Script do site, usado para os elementos interativos, como os botões e a troca de paleta de cores por gênero em `filmes.html`. |
| `flimes-dados.js` | Script do site, usado para guarda as cores do gêneros e informações de cada filme para ser usado em `filmes.html`. |
| `header.js` | Script do site, usado em todo o site para criar o menu de navegação em dispositivos móveis e telas pequenas. |
